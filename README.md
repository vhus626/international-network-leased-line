## 先确认资格：谁能办理国际网络专线

**只有企业能办，个人不在受理范围内。**审批备案由通信管理局负责，线路服务由三大基础电信运营商——中国电信、中国移动、中国联通——或其持牌授权的合作方提供。

这里有个容易混淆的点：市面上大量第三方跨境网络服务商（MKCloud 就属于这类），本身并不持有跨境运营资质。按工信部规定，中国大陆具备跨境业务运营资质的只有三大运营商，第三方的合规线路都是通过与运营商合作落地。这不影响你找第三方询价，但签约前要做一件事：让对方出示与运营商的合作资质，并把备案安排写进合同。

另一头，网上流传的那些便宜甚至免费的“跨境上网工具”，走的并非这条通道。企业业务跑在这类工具上，等于把合规风险留给自己。

## IPLC、IEPL、SD-WAN：三种主流线路怎么选

选型看两点：业务对稳定性的要求，和预算。传统专线稳但贵，SD-WAN 便宜灵活，轻中度业务够用。

**IPLC（国际专用线路）**走 SDH 光纤物理专线，网络具备自我修复能力，由双重网络运营中心 7×24 小时主动监控，SLA 普遍做到 99.99%。代价是价格，运营商直营报价里，香港方向 10Mbps 就要 8000–12000 元/月起。金融交易、关键业务系统选它。

**IEPL（国际以太网专线）**依托 MSTP 传输平台，标准以太网接口，速率 2Mbps 到 1000Mbps 可选，支持点对点和点对多点，适合需要在多地之间组网的企业。

**SD-WAN** 是软件定义方案，动态选路、按需购买带宽，部署快，成本约为传统专线的四到六成。代价是丢包和延迟略高，低价方案 SLA 多为 99.5%。

一个实用的判断规则：实时业务对延迟敏感，视频会议一般要求 200ms 以内，金融交易更苛刻，这类需求优先 IPLC/IEPL；日常跨境办公、ERP 访问、社媒和电商运营，SD-WAN 够用，省下的钱不是小数目。

## 办理流程六步走

国际网络专线的标准办理流程如下：

1. **前期准备**：明确跨境用途（办公、ERP、云访问、直播等）、所需带宽、目标国家或地区，选定持牌运营商或其授权服务商。
2. **提交申请与材料**：企业资质加用途说明交给服务商，由对方协助向通信管理局报备。
3. **受理与审核**：通管局做形式审查加实质审核，必要时现场核查。材料齐全的常规企业申请，多数走不到现场核查那一步。
4. **签约与部署**：审核通过后签约付款，服务商部署线路、完成跨境调测。
5. **验收与开通**：测试连通性、带宽和丢包，验收通过正式开通，验收报告自己留存一份。
6. **日常管理**：按规定报备使用情况，不得超范围使用。申请时写的是办公用途，实际就按这个用途跑。

## 材料清单：一次备齐，少跑一轮

申请材料分三块，提交前对照准备：

**企业基础资质**
- 营业执照副本复印件（加盖公章）
- 法定代表人身份证复印件
- 经办人身份证及授权委托书（法人亲自办理则免）
- 企业章程与股权结构

**业务合规材料**
- 跨境网络用途说明：写清用途、涉及的国家或地区、使用的系统
- 网络拓扑图与技术方案
- 数据安全与保密管理制度
- 承诺不用于违规用途的书面声明

**其他**
- 服务商专用申请表
- 办公场所证明（租赁合同或产权证明）

最容易漏的是企业章程与股权结构、办公场所证明这两样。很多企业第一次只带营业执照和身份证，来回补材料，一两周就这么耗掉了。

## 常见问题

**个人能办理国际网络专线吗？**

不能。国际专线只对企业主体开放，个人跨境联网只能走国家批准的正规通道，比如运营商提供的国际漫游等合法途径。

**从申请到开通要多久？**

全流程通常以周计，具体看审核进度和部署排期。审核环节是通信管理局的形式审查加实质审核，香港方向的常规方案最快。

**第三方服务商到底合不合规？**

判断标准就一条：线路是否通过与三大运营商的合作落地、能否完成通管局备案。签约前让对方出示合作资质，把备案安排写进合同，做到这两点基本没问题。

**香港方向和欧美方向怎么取舍？**

价格差 60%–70%，延迟表现也不同。成本敏感、业务以办公为主选香港；业务必须在欧美落地，再按欧美方向询价，部分优化线路延迟可控制在 180ms 以内。
